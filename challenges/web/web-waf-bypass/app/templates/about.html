About Corporate Portal

Enterprise product catalog and search system.

Security Features
  • Custom WAF v2.0 - blocks SQL injection patterns
  • Session-based authentication
  • Input validation on all endpoints
API Access

The system provides a REST API for programmatic access:

POST /api/search
Content-Type: application/json

{"q": "laptop", "cat": "Electronics"}
Note: The REST API accepts JSON requests for integration with third-party systems. Authentication via session cookie.
Stack
  • Python Flask 3.0
  • SQLite database
  • Custom WAF middleware
