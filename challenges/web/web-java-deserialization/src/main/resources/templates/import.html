Corporate Data Import System
Import Serialized Java Object

Paste a Base64-encoded Java serialized object to import it into the system.

Java serialized objects start with magic bytes rO0A (base64 of 0xACED0000)

To import a Java object:

          
    
            
  1. Serialize your Java object to bytes
    2. 
            
  2. Encode the bytes as Base64
    3. 
            
  3. Submit via this form or POST to /api/import
    4. 
          

          
Example using curl:

          
curl -X POST http://localhost:8080/api/import \
  -H "Content-Type: application/json" \
  -d '{"data": "rO0ABXNyABFqYXZhLnV0aWwuSGFzaE1hcAUH2sHDFmDRAwACRgAKbG9hZEZhY3RvckkACXRocmVzaG9sZHhwP0AAAAAAAAx3CAAAABAAAAABc3IADGphdmEubGFuZy5MbwT+F7vD7eCRAwAAeHBzcQB+AAIAAAAA"}'
